# Problem

Fictional teaching example: a reviewer asks for the recorded sampling interval to be
stated in Methods. The interval is present in the original protocol; the author has
not yet updated the manuscript. This is not an actual confidential reviewer comment.

# Original

We sincerely apologize for the limitations of our study. We have conducted a new
experimental campaign and revised the manuscript to validate all sampling settings.

# Diagnosis

The reply invents completed research and a completed revision. The question concerns
clarification of an existing method, not validation of every possible sampling setting.

# Rewrite

Thank you for requesting the sampling interval. We will add the interval recorded
in the original protocol to the Methods section so that the acquisition settings
are explicit.

# Why this works

Responds to the actual request using existing information. Prospective wording is
accurate because the edit has not been made. After implementing and checking the edit,
the author can change the tense and add its verified location. No line number is invented.
