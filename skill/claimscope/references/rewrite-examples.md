# Rewrite Examples

**What does a better revision actually look like?**

All cases are fictional teaching examples. Their stipulated evidence is not evidence
for any user's manuscript. Never introduce a fact from an example into a real paper.

## 1. Empty apology

**Before:** Unfortunately, this study only examines the tested temperature range.

**Diagnosis:** Apology without scientific content; range is necessary (A + B).

**After:** This study examines the tested temperature range.

**Why:** The research boundary remains; self-evaluation disappears.

## 2. Stacked hedging

**Before:** The measured response increased with temperature in each tested condition.
This might perhaps suggest a possible increase within the tested range.

**Diagnosis:** The second sentence weakens and repeats the stated observation (F).

**After:** The measured response increased with temperature in each tested condition.

**Why:** Reports the stipulated trend, not statistical significance or universal causation.

## 3. Positive scope

**Before:** We do not claim applicability outside the tested loading conditions.

**Diagnosis:** A necessary range expressed as defensive denial (B).

**After:** The conclusion applies to the tested loading conditions.

**Why:** Does not invent parameters or imply untested validation.

## 4. Scope versus flaw

**Before:** The study concerns dry specimens, but unfortunately no wet specimens were tested.

**Diagnosis:** If the stated research question is dry-specimen behavior, this is scope (B).

**After:** The study characterizes dry-specimen behavior.

**Why:** Valid only for that stated question. If the paper claimed all moisture states,
narrow that claim; do not hide the missing evidence by renaming it scope.

## 5. Formulaic transition

**Before:** It is worth noting that, furthermore, the curve has loading and unloading stages.

**Diagnosis:** Transitions add no argumentative relationship.

**After:** The curve has loading and unloading stages.

**Why:** Preserves the classification without ornamental prose.

## 6. Observation versus mechanism

**Before:** The response increased, unquestionably proving a structural rearrangement.

**Diagnosis:** In this fictional case only the response was measured, not structure.

**After:** The measured response increased.

**Why:** Removes unsupported proof. Discuss structural change as a hypothesis only
when an actual rationale is available; do not invent one to complete the paragraph.

## 7. Supported discussion

**Before:** Both measurements retain a residual offset after unloading. This might
perhaps indicate that the response did not fully recover.

**Diagnosis:** Directly supported interpretation is unnecessarily hedged.

**After:** Both measurements retain a residual offset after unloading, indicating
incomplete recovery.

**Why:** Does not assert a particular microscopic cause.

## 8. Conclusion without a disclaimer tail

**Before:** The tested specimens retained residual deformation. Despite these useful
findings, many shortcomings remain and substantial further work is needed.

**Diagnosis:** Generic self-assessment contains no actual limitation (A).

**After:** The tested specimens retained residual deformation.

**Why:** Retains the finding and its subject; actual limits would still need reporting.

## 9. Reviewer response without added work

**Before:** We apologize and will test many additional conditions to clarify the protocol.

**Diagnosis:** The fictional comment asks for a protocol detail already recorded,
and no revision has yet been made.

**After:** Thank you for requesting this clarification. We will state the recorded
protocol explicitly in the Methods section.

**Why:** No new experiments or false claim that a revision is complete.

## 10. Diary to argument

**Before:** We ran condition A, then B, then compared them. The response was lower in B.

**Diagnosis:** Sequence obscures the stated result.

**After:** The response was lower in condition B than in A.

**Why:** Leads with the observed comparison without adding a cause or broader trend.

## 11. Keep a decisive limitation

**Before:** Unfortunately, the sensor saturated near the peak, so the peak is unknown.

**Diagnosis:** Measurement limitation determines claim validity (C).

**After:** Sensor saturation near the peak prevents determination of the true peak value.

**Why:** Removes apology, not the limitation.

## 12. Retain a useful contrast

**Before:** Residual deformation is not the same quantity as maximum deformation.

**Diagnosis:** This contrast defines distinct variables (E).

**After:** Residual deformation is not the same quantity as maximum deformation.

**Why:** No rewrite is needed just because a sentence contains a negation.

## 13. Keep a negative statistical result

**Before:** Unfortunately, the test detected no statistically significant difference.

**Diagnosis:** Assume an appropriate test actually exists; its outcome is essential (D).

**After:** The test detected no statistically significant difference.

**Why:** Nonsignificance is not equivalence and must not become a superiority claim.

## 14. Chinese scope calibration

**Before:** 本文并不声称这些结果适用于所有材料，换言之，不适用于所有材料。

**Diagnosis:** 范围声明与重复澄清混合（B + F）。

**After:** 本文结论限定于所研究的材料。

**Why:** 保留真实范围，删除重复；材料名称已知时应写出具体名称，不自行补充。
